**Debian Gnome Desktop**
```bash

```

**Debian KDE Desktop**

## Arch-Linux
**Arch-Linux KDE Desktop**
```bash
curl -s https://raw.githubusercontent.com/celik23/bash/main/arch-kde.sh | bash -s -- arg arg
```
